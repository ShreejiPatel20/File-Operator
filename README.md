## 🚀 How to Run

### Step 1 — Keep the files together

Place the Python file and CSV file in the same project folder.

### Step 2 — Run the program

```bash
python "File Oprator(1).py"
```

Or, on systems using Python 3 explicitly:

```bash
python3 "File Oprator(1).py"
```

### Step 3 — View the output

Open `output(4).csv` to inspect the processed data.
